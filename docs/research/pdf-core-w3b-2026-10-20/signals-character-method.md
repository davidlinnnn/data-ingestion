# Stage5 pre-feature normalization and distance

Frozen before BEGIN5; no R1 or labeled-cohort features read. Authoritative executable details and SHA are in signals-character-method.json.

Code and descriptions use NFC and preserve indentation, whitespace, quotes, string contents, identifiers and symbols. Formulas only fold explicit mathematical alphabet font codepoints and seven named typography ligatures; other Unicode compatibility changes are forbidden. Formula whitespace is removed for character distance only; ordered operator and number checks use original NFC visible content.

TeX first becomes PresentationMathML, then visible leaf glyphs with explicit row/fraction boundaries; raw TeX control-command length is never compared against PDF text. Unknown commands are UNKNOWN. 2D scope/attachment is not proven by the resulting string. Exact dynamic-programming Levenshtein defines 1-d/maxlen; no difflib/CER substitution.

b requires the same PDF SHA, original page and an explicit frozen crop/ref/equation identity, never matching by output similarity. c will actually render sanitized local MathML in isolated Chrome, with per-unit bbox and screenshot; conversion-only is not rendering and successful rendering is not semantic proof.

Threshold .95 and exact operator/number sequences remain unchanged. Missing signals mean NO_DECISION. Original block/code labels are not expanded into invented line labels; metadata/alignment exclusions and unknown-label verified counts remain explicit.
