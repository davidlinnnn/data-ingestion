# V4 backend 消融：固定版本官方原始碼預檢

此記錄僅讀本機已安裝程式碼；未下載、載入模型或執行 conversion。docling-slim=2.132.0；docling-parse=7.22.3。以下是原始碼可支持的預期，不是實測修復結論。

- 官方 PdfFormatOption 的預設 backend 是 ThreadedDoclingParseDocumentBackend；舊 DoclingParseV4DocumentBackend 是向同一 threaded class 轉交的 deprecated alias。見 <tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/document_converter.py:302 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/document_converter.py:302`)、docling_parse_v4_backend.py:17 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/docling_parse_v4_backend.py:17`)。因此本輪請記錄 actual class 與 effective backend options，不能只寫「v4」。
- 舊 PyPdfiumDocumentBackend 逐一 get_rect 後呼叫 get_text_bounded，再以橫向合併後的聯集 bbox 重查 get_text_bounded。這提供先前 clipped 舊文字與重疊字流在原生 cells 擴增的機制；並非 Markdown 自行複用同一段。見 pypdfium2_backend.py:291 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/pypdfium2_backend.py:291`)、同檔:407 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/pypdfium2_backend.py:407`)。
- threaded parse backend 的 get_text_cells 直接取 parser textline_cells；get_text_in_rect 以已有 textline cell 的 intersection_over_self >0.5 選取並串接，不採用 PDFium 合併 bbox 後重查原始文字。見 docling_parse_backend.py:142 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/docling_parse_backend.py:142`)、同檔:173 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/docling_parse_backend.py:173`)。因此「backend 重查放大」有機會改變；仍不能從程式碼保證 caption／正文不重複。
- DecodeConfig 預設 do_sanitization=True、min_visible_clip_extent=1e-3、apply_actual_text=True，這些值送入 native _DecodePageConfig；PageBoundary 預設 CROP_BOX。見 pdf_parser.py:228 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling_parse/pdf_parser.py:228`)、同檔:254 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling_parse/pdf_parser.py:254`)、同檔:1117 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling_parse/pdf_parser.py:1117`)。本機 Python wrapper 可證參數與邊界選擇；native C++ 裁切實作未在這裡驗證，不能據欄位名稱斷言所有 clip／頁外／遮蓋文字均被刪除。
- get_visible_text_cells 只明確濾除 rendering_mode INVISIBLE 與 ONLY_CLIPPING。見 docling_parse_backend.py:64 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/docling_parse_backend.py:64`)、同檔:179 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/docling_parse_backend.py:179`)。P10/P20 舊案例部分文字是 FILL、黑色、位於自身矩形 clip 外；不能把 render-mode 過濾等同這些案例的確定解法。
- backend 預設 parser_threads=None（回退 accelerator threads）、render_pages=True、render_scale=1.0、release_native_memory_every_n_pages=128。見 backend_options.py:301 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/datamodel/backend_options.py:301`)、backend construction:285 (`<tmp>/pdf-core-native-std-20261017/venv/lib/python3.12/site-packages/docling/backend/docling_parse_backend.py:285`)。pipeline generate_page/picture_images=False 不等於 backend render_pages=False；本輪仍需 layout 的頁圖，兩者不可混淆。只讀記錄，不變更設定。

六篇原 baseline 的13組來源檢查已凍結於 comparison/recovery-sourcechecks.json，含 P20 footer、caption 混段、Sudoku、P10/P20 頁外舊文字，以及兩個 incidental 群。判斷 whole fix 必須同時核對 native text/orig、父層、Markdown 與可見原頁；只改 caption role 或只減少機器候選是 partial／persist 的可能情況。
