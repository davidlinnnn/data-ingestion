# W3 formula/code source-only oracle v1

Only frozen LaTeX source archives, W2 source-only anchors, and original PDF text layers are read before freeze. No Docling document/Markdown, conversion, model inference, network request or TeX execution is used. Adam has only an includepdf wrapper and is UNKNOWN_NO_BODY_LATEX.

A displayed formula unit is one outer equation/align/gather/multline/eqnarray (including starred forms), displaymath, \[...\], or $$...$$ block. Nested aligned/matrices belong to the parent. Top-level \\ rows are preserved as ordered diagnostic subunits; the outer block is the denominator and family sample unit, avoiding double counting. Row splitting respects braces and nested environments. Inline $...$ and \(...\) source spans are registered separately and never called observed flattening losses.

Literal lstlisting/verbatim/Verbatim/minted/tcblisting retain original contents. Recognized explicit prompt/code boxes (including source-declared SICA tracebox) are recorded as TeX prompt units; if they wrap a literal code environment, only the literal child is counted. Algorithm/algorithmic outer containers are one unit with whitespace-normalized macro/line order; no unknown macro is guessed or executed. Comment masking preserves source offsets and literal code percent signs. Input/include expansion is archive-internal with command boundaries; unresolved dynamic inputs and parser mismatches remain in source audit. Raw source, archive/file/unit SHA256, source line/offset, expanded offset, and unknown commands are retained.

PDF location is independent of conversions. Unique literal/code text anchors identify pages or a start/end page range. Nonfloating display math may be placed only when nearest trusted source-body anchors on both sides locate to the same PDF page. Other context/caption pages remain candidates, not assignments; unresolved locations and selected-page scope remain UNKNOWN. Source order and rows are never reordered using PDF order. F scope remains first12pages; source units beyond the selection are OUT_OF_SCOPE.

Sampling is frozen before E0/E1 scoring. Seed W3-formula-code-source-v1-20261020; SHA256(seed|unit_id|raw_sha256). If E1 cost exceeds2hours, each declared layout family contributes at most40 formulas by ascending hash; all code/algorithm units are retained. Unknown-page source units remain visible and are not replaced with convenient examples. E1 cost probes are predeclared F-ieee_crnn and P07 SICA. The50 close/error audit uses20 formula,15 code,15algorithm slots and deterministic hash order, with prespecified round-robin transfer when a category is sparse; no retrospective case selection. See sample-plan.json for exact unit IDs and ordering.

Limitations: LaTeX is not compiled; arbitrary macros, conditionals, packages and custom listing import commands may hide unrecognized structure. The oracle is structural source inventory, not a symbolic equivalence solver. Macro tokens and mathematical identifiers are preserved rather than normalized to superficially similar rendered strings. Page textlayer ligatures, code line wrapping, duplicate snippets and floats can prevent unique positioning. UNKNOWN is not a missing-output defect. Semantic adjudication must verify quantities, signs, superscripts/subscripts, conditions, object membership and ordered algorithm steps using original page images. Missing or near string matches are candidates only.

For E1 delivery evaluation, RAW active text/Markdown and MAPPED fallback are separate. MAPPED may fall back to orig only when active text is empty; nonempty wrong model text cannot be rescued by a union with orig. orig remains diagnostic source evidence, not a model reconstruction success.
