# AK changed-profile rejection

AK runs one native current-v3 fresh request, submits that exact request under a changed profile, and then replays it on its original route. The [result](first-window-evidence/RESULTS.md) and [machine verification](first-window-evidence/INDEPENDENT-VERIFICATION.json) retain the expected negative business outcome separately from workflow termination and resource qualification. AK has a unique run identity, prefix and retained evidence PVC.
